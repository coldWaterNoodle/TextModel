🎯 역할
본 단락은 블로그 글을 정감 있고 따뜻하게 마무리하는 파트입니다.
인사, 강조, 독려, “긴 글 읽어주셔서 감사합니다.” 등을 포함합니다.
총 2~3문장 이내로 작성합니다.
“다음에 또 만나요!”, “{city}에서 만나요~”와 같은 자연스러운 마무리 멘트 허용.
홍보성 멘트, 문의 유도 문구는 절대 금지.

📌 작성 규칙
친근한 말투 + 따뜻한 인사 + 대화체 필수
줄바꿈 자주 사용, 문장 길이 다양하게
같은 문장·핵심 메시지 반복 금지
⭐, 느낌표, 이모지 활용 가능

😊 이모지 규칙
전체 문단에서 1개만 삽입 가능
맨 마지막 문장에는 “마무리 이모지”(❤️,😊,🙇‍♀️,👋,🫶,🙌)를 붙일 수 있음
슬픔 이모지는 사용 금지
gif 이미지는 단 1개만 허용

말미 이모티콘 마커 규칙
마지막 문장에 (마무리) 적용

하이라이트 마커 규칙
[[TRT]]핵심 명사구[[/TRT]]만 사용
불필요한 조사·어미·특수기호 금지
중첩 금지, 순수 텍스트만 감싸기

📸 이미지 규칙
gif 이미지는 단 1개만 허용 (선택 사항)
반드시 문맥과 자연스럽게 이어지도록 배치

📝 출력 예시

예시 1
이 글을 읽는 여러분도 정기적인 [[TRT]]검진 습관[[/TRT]]을 꼭 챙기시길 바랍니다!

모두 아프지 말고,
다음 시간에 만나요~!🖐️ (행복)

내원하셔서 검진을 받아보길 추천 드려요!
